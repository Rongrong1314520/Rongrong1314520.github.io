銅匠實驗室#

免費開源的高中科學 3D 實驗課件。

物理、化學、生物、地理 54 門課已上線，按人教版教材章節持續更新。每門課都是一個 HTML 文件，打開就能講，斷網、投影、電子白板都能用，也能嵌進學校網站或學習平台。

最難得的是，這是一個人加 AI 做出來的整座 3D 實驗室，教材數據都有出處。

開源倉庫：github.com/smithjohn78390/tongjiang-lab

中小學·高中知識圖譜#

從小學到高中的學習好幫手。

覆蓋數學、語文、科學、道德與法治、歷史、英語、物理。選一個知識點，它會沿著先修關係自適應出題，先問目標本身，答錯再往回追，找到真正沒學會的那一步，再按年級從低到高排出補學順序。

開源倉庫：github.com/xiaoyang111222/cn-math-taxonomy

高性價比人生指南#

用最少的錢、時間和精力，換回壽命、金錢和人身自由。

每條建議都回答兩個問題：花掉什麼，換回什麼。換回的算在誰頭上也分檔：自己最高，其次配偶和直系親屬，再次朋友同事，陌生人最低——最低不等於零，只是回報的指望小、要連風險一起看。

不用全做：這是一份備選單，不是任務清單，挑一兩條就算數。還附生活自查問卷和十來篇長文（被裁、換城市、確診慢性病、孩子出生前後……），以及讓 Claude Code 或 Codex 照這本書回答問題的 skill。正文按 CC BY 4.0 發布，來源核實過程也公開。

開源倉庫：github.com/eternity4719/HowToLiveBetter

HEYPCB Circuit World#

開源硬件電路板的目錄，收了 1.5 萬多塊別人已經做好的板子。

口號很直白：找一塊別人做過的板子，從它開始做自己的。按分類和平台都能找：機器人、鍵盤、音頻、射頻、電源、物聯網，ESP32、Arduino、樹莓派、STM32、RP2040 都在；每塊板子標著作者、零件數和板子尺寸，還有給新手的簡單入門板。

完整瀏覽要登錄賬號，免費開始，不用信用卡。

立創開源硬件平台#

嘉立創旗下的中文開源硬件分享平台。

首頁有推薦項目、項目合集、教程視頻、文章和貢獻者排行，還有開源集市。點進一個項目，能看到完整介紹、設計文件、BOM、3D 模型和附件；不少是 Arduino、ESP、STC 這些開發板項目，還有大學計劃和課程案例。

看項目不用登錄，免費；集市裡的實物硬件要另外買。

AgentRoute#

面向 AI 智能體的分流規則，每天整理一份，交給 Agent 幫你接入。

規則很簡單：國內網站直連，海外網站走你自己的節點，名單裡的廣告攔掉，內網不受影響。它只提供規則，不提供節點或機場訂閱，也不是代理軟件；有 Mihomo / Clash Meta、Surge / Shadowrocket、sing-box 三種格式，校驗失敗時保留上一份有效數據。

用法是複製一段提示詞給自己的 Agent（Claude Code、Codex），由 Agent 按文檔接入、備份、驗證，還附 DNS 和 WebRTC 防護指南，以及同步、驗證、回滾工具。

江山時序#

中國歷史交互地圖時間軸，從戰國一直拉到現代。

一幅圖裡裝了 2400 多年、18 個歷史時期：拖動時間軸就能看疆域怎麼起落，點任何一座古城或名關，會跳出它兩千四百年的沿革卡片——這個地方歷代叫過什麼名字、歸哪個州郡管、在這裡發生過哪些大事。還能跟著歷史人物走：秦始皇統一、張騫出使、諸葛亮北伐、玄奘取經、李白漫遊、蘇軾貶謫，一步步在地圖上重走一遍，走到哪首詩就是在哪寫的。

另外有個小測驗：地圖上不標地名，給朝代線索讓你落針猜古城，10 輪下來按距離打分，還會授一個古代官職頭銜。免費開源，瀏覽器打開就能玩，網站界面是簡體中文。

開源倉庫：github.com/DeanChensj/jiangshan-map

吟詩#

給古詩自動注上拼音的詩詞閱讀器。

一張宣紙，一首詩，字上帶拼音。宣紙水墨風設計，接入海量古詩詞庫，按詩名、詩人、詩句都能搜；橫排、豎排、田字格三種版式隨便換，多音字按統編語文教材的讀音校正，點任何一個字都能改讀音，還能切換吟誦舊讀，簡體繁體一鍵切換。

附帶遮字背誦、飛花令、今日一詩、詩人足跡地圖，還能朗讀、默寫、收藏打卡，一鍵打印、導出圖片、複製帶拼音文本。不用註冊，不裝軟件，所有記錄只留在自己的瀏覽器裡；還有小紅書離線版，收了統編課本 237 首，沒網也能打開。

開源倉庫：github.com/TTNAN/yinshi

hagezi DNS Blocklists#

全網攔截廣告、追蹤、釣魚和惡意網站的 DNS 攔截清單。

一份清單擋掉廣告、追蹤器、遙測、釣魚、惡意軟件、詐騙和假網站，整個家裡的設備都能受益。分五檔：LIGHT、NORMAL、PRO、PRO++、ULTIMATE，越往上攔得越狠，也越可能誤傷；新手照作者建議，用 Multi PRO 再加一份 Threat Intelligence Feeds 就好。

支援 Pi-hole、AdGuard Home、uBlock Origin 等常見工具，有 Adblock、DNSMasq、Wildcard、RPZ 幾種格式，還有直接生成下載鏈接的工具，不用自己挑格式。

GPL-3.0 開源，GitHub 2.8 萬星。

English Vocabulary Vault#

960 多本英語單詞書的開源詞庫，從小學一路收到博士。

按階段和考試分好類：中小學同步教材、四六級、專四專八、考研 190 本、雅思 28 本、托福 21 本，還有新概念英語 1-4 冊加 108 篇精講筆記，以及計算機、商務英語。詞表都是 .xlsx 或 .txt，帶國際音標和釋義，能直接導進 Anki、Quizlet、歐路詞典背。

CC BY-NC-SA 4.0 開源，免費。

PicLex 攝影學英語#

用照片學英語的開源 Web 學習器，打開瀏覽器就能用，不用登錄。

從喜歡的電影開始：在《阿甘正傳》《教父》《星球大戰》的熟悉畫面裡記單詞，用經典台詞練聽力和口語，一套 100 張電影卡片、100 個目標詞。也有英文歌、日常生活、程序員英語、攝影等主題卡組，還能導入自己的 .piclexdeck。

也可以從自己的生活出發：拍一張照片或導入一張，生成雙語標籤和場景例句，開始練習。還有個小遊戲「薯薯求生」：拼對單詞才能把裝備帶走。進度存在瀏覽器裡，配好 WebDAV 可以跨設備同步。

開源倉庫：github.com/zhaoolee/piclex-web

音乐 1001#

按 Hacker News 和 Reddit 的討論熱度排的音樂榜，1 到 1001 首。

從流行歌到古典器樂，從錄音室到現場：兩邊社區都在聊的歌排得更高，同一首歌的不同表演版本（翻唱、現場、混音）可以各自上榜。每條上榜記錄都對應一個 YouTube 版本，點開就能聽。

排名只看討論熱度，不看播放量：HN 看貼文得分和回覆，Reddit 看討論串和提及次數，兩站分數各自換算成 0–100 再合併。部分曲目受 YouTube 地區和版權限制，要回 YouTube 原站播放。

Awesome#

GitHub 上最出名的精選清單總索引，53 萬多星。

它自己不放資源，而是把幾百份人工精選的清單串成一個入口：編程語言、平台、前端、後端、計算機科學、書籍、學習、安全、娛樂、健康——每個主題點進去，都是一份單獨維護的清單，裡面才是挑過的工具、庫和資料。想找任何領域的入門資源，先到這裡翻目錄，基本不會空手而歸。
